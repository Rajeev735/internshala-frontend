# Smart CRM Frontend 🚀

Frontend for the Smart CRM platform built using React, TypeScript, Tailwind CSS, and Vite.

---

# 🔥 Live Demo

https://internshala-frontend.vercel.app/

---

# 📌 Features

- JWT Authentication
- Role-Based Access Control
- Responsive Sidebar
- Lead Management UI
- Debounced Search
- Pagination
- CSV Export
- Protected Routes
- Mobile Responsive Design

---

# 🛠️ Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- React Router DOM
- Axios
- React CSV
- Vite

---

# ⚙️ Environment Variables

Create `.env` file:

```env
VITE_API_URL=https://intershala-backend-up65.onrender.com
```

---

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Rajeev735/internshala-frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Development Server

```bash
npm run dev
```

---

# 🐳 Docker Support

This project includes Docker support using a Dockerfile.

## Build Docker Image

```bash
docker build -t smart-crm-frontend .
```

---

## Run Docker Container

```bash
docker run -p 5173:5173 smart-crm-frontend
```
